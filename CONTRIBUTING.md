# Contributing to AI Labs

Thank you for contributing to this AI Labs repository! 🎉

## Adding a New Lab

1. **Create your notebook** in the `labs/` directory
2. **Name it descriptively**: `Topic-Name-Lab.ipynb`
3. **Structure your notebook**:
   ```
   # Lab Title
   
   ## Overview
   Brief description of what this lab covers
   
   ## Prerequisites
   What knowledge/libraries are needed
   
   ## Setup
   Any imports or configuration
   
   ## Sections
   Organize content into logical sections
   
   ## Exercises (optional)
   Practice problems for learners
   
   ## Conclusion
   Summary and next steps
   ```

4. **Update the README**:
   - Add your lab to the "Labs Collection" section
   - Include brief description and topics covered
   - Update the "Latest Updates" section

5. **Update requirements.txt** if you use new libraries

6. **Test your notebook**:
   ```bash
   jupyter notebook labs/your-new-lab.ipynb
   # Run all cells to verify it works
   ```

## Commit Guidelines

Use clear commit messages:
- `Add: New lab on [topic]`
- `Update: Improved [lab name] with [changes]`
- `Fix: Corrected [issue] in [lab name]`
- `Docs: Updated README with [changes]`

## Quality Standards

- ✅ All code cells should run without errors
- ✅ Include markdown explanations before code
- ✅ Show example outputs
- ✅ Use meaningful variable names
- ✅ Add comments for complex logic
- ✅ Keep notebooks focused on one topic
- ✅ Test in a clean environment
