## 🚀 Quick Start

### Running in GitHub Codespaces (Recommended)

1. Click the green "Code" button → "Codespaces" tab
2. Click "Create codespace on main"
3. Wait for automatic setup
4. Navigate to `labs/` directory
5. Open any notebook and start learning!

### Running Locally

```bash
# Clone the repository
git clone https://github.com/biso1991/ai-labs.git
cd ai-labs

# Install dependencies
pip install -r requirements.txt

# Launch Jupyter
jupyter notebook
```

## ➕ Adding New Labs

To add a new lab:

1. Place your notebook in the `labs/` directory
2. Update this README with lab description
3. Add any new dependencies to `requirements.txt`
4. Commit and push:
   ```bash
   git add labs/your-new-lab.ipynb
   git commit -m "Add: Your New Lab Title"
   git push
   ```
