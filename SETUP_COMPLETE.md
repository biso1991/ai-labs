## ➕ Adding New Labs

When you're ready to add more labs:

1. **Place notebook in labs/ directory**:
   ```bash
   cp "/path/to/your/notebook.ipynb" ~/Desktop/ai-labs/labs/
   ```

2. **Update README.md** with lab description

3. **Commit and push**:
   ```bash
   cd ~/Desktop/ai-labs
   git add labs/your-new-notebook.ipynb
   git add README.md  # if you updated it
   git commit -m "Add: Your Lab Title"
   git push origin main
   ```

### Quick Add Script

For future labs, you can use this command:

```bash
# Add a new lab
LAB_FILE="/path/to/new/lab.ipynb"
LAB_NAME="Your Lab Name"

cd ~/Desktop/ai-labs
cp "$LAB_FILE" labs/
git add labs/
git commit -m "Add: $LAB_NAME"
git push origin main
```
